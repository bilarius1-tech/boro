# TG + Share logistics

## Канал @boroboroxolka

### Публикация (одна карточка)
- **1 фото:** одно сообщение — фото + название / цена / описание + ряд кнопок  
  `[Открыть на Boro →] [Добавить своё]`
- **2+ фото:** альбом с той же подписью + **одно** короткое сообщение-ответ с теми же двумя кнопками  
  (у `sendMediaGroup` Telegram не даёт inline-кнопки — это ограничение API)
- Отдельного поста-рекламы больше нет — CTA «Добавить своё» в кнопке

### Клип
- Если выбран — догоняет **ответом** к карточке (без второй рекламы и без лишних кнопок)
- `message_id` клипа дописывается в `telegram_message_ids`

### Продано
- Сайт — удалить лот
- Канал — ответ `✅ ПРОДАНО` + кнопки → `✅ Продано`

### Удалить
- Сайт — hard delete (Storage + БД)
- Канал — `deleteMessage` по всем id из `telegram_message_ids`

### Шаринг с сайта
- Web Share: заголовок + мини-текст про Boro; URL отдельно (OG-карточка)
- OG: брендовая картинка (фото + название + цена)
