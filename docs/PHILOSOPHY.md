# Философия Boro

## Суть одной фразой

Вещи Боровичей: сфоткал → написал → цена → карточка + канал → договорились в личке.

## Зачем

Авито и большие площадки шумные, чужие, с комиссиями и доставкой «на всю Россию».  
Boro — **локальный** контур доверия: город Боровичи, люди рядом, без магазина.

## Что мы есть

- Личная (и позже городская) **лента объявлений**
- Быстрый пайплайн «выложить»
- Зеркала в привычные каналы города: **Telegram** и **ВКонтакте**
- Шаринг ссылки с нормальной карточкой (OG)

## Что мы не есть

| Не делаем | Почему |
|-----------|--------|
| Маркетплейс / витрина как Ozon | Ломает простоту |
| Корзина, оплата, эскроу | Сделка в личке |
| Категории, фильтры «как на Авито» | Phase 0 не про поиск по таксономии |
| Внутренний чат | Есть WA / TG / телефон |
| Мультивендор-биллинг | Рано |
| Навязанный VPN-бот как единственный вход | В РФ веб надёжнее |

## Принципы дизайна продукта

1. **Один жест публикации** — минимум полей, сильное сжатие фото, быстрый upload.
2. **Карточка = правда** — сайт источник истины; TG/VK зеркала.
3. **Одна карточка в канале** — не спамить тремя сообщениями рекламы; CTA кнопками.
4. **Продано уважает историю** — в канале эмблема, не чёрная дыра (кроме явного «Удалить»).
5. **Город в ДНК** — дефолт `Боровичи`, копирайт и пустые состояния про город.
6. **RF-first** — WhatsApp/телефон обязательны в контактах; веб — основной create.

## Петля ценности

```
ФОТО + ТЕКСТ + ЦЕНА
        ↓
   КАРТОЧКА /i/[id]
        ↓
   TG-канал  +  VK-группа  (+ опц. клип)
        ↓
   SHARE (VK / MAX / TG / copy)
        ↓
   КОНТАКТ В ЛИЧКЕ → сделка
```

## Фазы

| Фаза | Смысл |
|------|--------|
| **0 (сейчас)** | Личный пайплайн + зеркала + клип + шаринг |
| **1** | Жители Боровичей, лента города |
| **Позже** | Explore / WANT — только если Phase 0 доказал привычку |

## Тон

Прямой, городской, без «AI-стартап» воды. Бренд **Boro** читается сразу; интерфейс — спокойный mobile-first, без дашборд-шума.
