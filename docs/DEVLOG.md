## Бриф: лента «залипнуть в туалете»

### Принцип

Главная = **живая лента**, не пустой лендинг. Герой короткий → сразу карточки. Скролл как в соцсети.

### UX

- Mobile-first **app-shell**: колонка ~`max-w-lg` по центру и на десктопе (ощущение приложения).
- Карточка: крупное фото, цена, название; тап → `/i/[id]`.
- **Infinite scroll** (подгрузка страницами), без «страница 2».
- Sticky низ: `Лента` · `+` · `Профиль` (или Войти).
- Пустая лента: дружелюбный empty + CTA «стань первым» / бета.
- PWA-lite позже: `manifest` + theme-color + standalone (после ленты).

### Данные

Пока Phase 0: все `ACTIVE` лоты города (или все активные).  
Позже Phase 1: фильтр по `city`, multi-user.

### Технически (когда делать)

- `GET /api/feed?cursor=&limit=` или server + client infinite
- Карточки без тяжёлых карточных рамок (фото = якорь)
- Сжатые JPEG уже есть — не раздувать
